## Git
To contribute to this project, first create a [fork of this repository](https://github.com/CS-Club-UAA/PacMan/fork) (uncheck "Copy the main branch only"). 

Create a new branch, make your changes, then create a pull request.

```sh
git clone https://github.com/YourUsername/PacMan
git checkout -b newBranchName

```
